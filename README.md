## What is it about
Spider maze is a game in which you have to escape a very dark maze to find a white orb hidden at the end of it, while avoiding the creepy spider lurking in the darkness. 
Do you think you'll be able to escape?

## Building
Alredy builded realeses in _[here](https://github.com/LCdev1234/Spider-Maze/releases)_

If you'd rather build the game yourself:
1. Clone or download the repository and open a terminal in the project directory.
2. Install the dependencies:
   ```npm install```
3. To run the game locally:
   ```npm run dev```
4. To build the game:
  ```npm run build```
